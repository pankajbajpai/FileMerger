File Merger

Merge or convert PDF, Excel (xlsx/xls/csv), and Word (docx) files into a single output file. You can mix file types — the output format is decided by the extension you type below.

Files never leave your machine's local server. If a file is password protected, you'll be asked for its password only after it's detected — no need to mark it yourself. Output can be .pdf, .docx, or .xlsx; if your files are all the same family as the output (e.g. all Excel-family files → .xlsx), a high-fidelity merge is used. Otherwise files are converted (best-effort, text and tables preserved) into the target format before merging.
